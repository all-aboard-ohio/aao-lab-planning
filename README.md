# AAO Data Lab — Project Planning

This repository is the org-level project tracker for the [All Aboard Ohio Data Lab](https://lab.allaboardohio.org).

Use it to **propose new tools, analyses, and research projects**. Issues here represent ideas and scoped proposals. Once a project is approved and a contributor is ready to build, it gets its own repository bootstrapped from a template.

---

## Proposing a New Project

Open an issue using one of the templates:

- **New Tool or App** — for deployable web tools (maps, calculators, data dashboards, PWAs)
- **New Analysis or Research** — for data models, Jupyter notebooks, cleaned datasets, and research deliverables
- **Bug Report** — for reporting bugs across any AAO Data Lab repo

Before filing, mention your idea in [#projects on Slack](https://join.slack.com/t/lab-allaboardohio/shared_invite/zt-3x7cyvl53-0IQMjvljmA64iNCZvhaP1w) so maintainers can help you scope it.

---

## Starting a New Repo

When a project is approved, use one of these template repositories to bootstrap it:

| Template | Use For |
|---|---|
| [aao-lab-template-tool](https://github.com/all-aboard-ohio/aao-lab-template-tool) | Web tools, apps, dashboards — React + Vite + Tailwind, AAO components pre-wired, GitHub Pages deploy action included |
| [aao-lab-template-analysis](https://github.com/all-aboard-ohio/aao-lab-template-analysis) | Data analysis, models, notebooks — Python + Jupyter with standard folder structure |

Click **"Use this template"** on the template repo to create your new repo, then link it back to your planning issue.
